# Project Documentation

Start here to understand what this project is and where it's going.

- **[product-overview.md](product-overview.md)** — what the product is, who
  uses it, the key business rules, and what exists today vs. what's planned.
  Read this first.
- **[features.md](features.md)** — the authoritative feature list per role
  (customer, operator staff, admin), with implementation status.
- **[domain-model.md](domain-model.md)** — entities, relationships, the
  mail-item state machine, and open design questions.
- **[notes.md](notes.md)** — reviewer notes and cleanup tasks for the
  codebase.

Keep these current: when a feature ships, flip its status in `features.md`;
when an open question in `domain-model.md` gets decided, record the decision
there.
